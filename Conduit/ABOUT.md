## Agent-Human Interaction Boundaries

Conduit is designed for **autonomous collaboration**, but the human user remains the final authority. 

### 1. The Hand-off Protocol
If an agent encounters a block (e.g., "Missing API Key", "Need Design Decision"), it must:
- Log a **Handoff** entry in the timeline.
- Set its status to `blocked`.
- Provide a summary of the context to the human.

### 2. Human Overrides
Humans can override agent intents by:
- Updating `plans` in the sidebar.
- Using the `agent_bridge --approve` command to unblock sensitive tasks.
- Manually editing `context.json` to reset session states.

### 3. Safety Limits
- Agents cannot modify `.vscode/` settings without explicit approval.
- Destructive commands (e.g., `git reset --hard`) require the `--approval` flag via the bridge.
